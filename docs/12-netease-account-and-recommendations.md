# 网易云账号绑定与个性化推荐实施方案

状态：两端代码已实现，自动化回归与本机原生构建通过；真实账号、NAS 出口及 iOS 真机验收待完成。日期：2026-10-30。

涉及仓库：后端 `F:/cyapi-go`；客户端 `F:/CyreneMusic`。本文统一约束两端，不改动现有运行配置。

## 1. 目标与范围

在现有 Go 单程序、SQLite/PostgreSQL 和 Flutter 客户端上完成：网易云官方网页登录、备用扫码绑定、个人歌单读取与批量导入、每日推荐歌曲、每日推荐歌单、私人 FM、过期重绑和解绑。

不引入 Node 服务、第三方音乐 API 代理、Redis 或额外 NAS 容器。绑定信息由 NAS 按 Cyapi 用户管理，同一 Cyapi 账号在不同设备共享绑定。

设置入口继续叫“第三方账号”。网易云提供实际功能，酷狗显示“暂不支持”并禁用绑定按钮。页面说明明确个性化推荐来自网易云。

第一版只读取网易云数据：不回写平台收藏、删除或修改平台歌单，不做签到、打卡、播放历史上报和 FM 垃圾桶反馈。Cyapi 收藏仍是 Cyapi 收藏。播放继续使用现有音源和播放器；绑定不承诺解锁会员、版权或改变现有解析优先级。

## 3. 登录方式和可行性门槛

| 平台 | 主方式 | 备用方式 | 发布前验证 |
| --- | --- | --- | --- |
| Windows | 独立官方网页登录窗口，优先系统 WebView2 | 由 NAS 创建并验证的二维码 | Cookie API、HttpOnly 读取、独立会话、运行时检测、release 打包 |
| Android | App 内原生 WebView 打开官方手机登录页 | 二维码供另一设备扫描 | 官方页面登录、必要 Cookie、前后台切换、App 跳转 |
| iOS | 原生 WKWebView 打开官方手机登录页 | 二维码供另一设备扫描 | 真机 Cookie 与导航、返回、会话清理；未验证不得宣称支持 |

网页登录是默认产品方案，具体登录方式由官方页面提供，不承诺短信、密码、扫码、第三方授权在所有环境均可用。官方页面产生的受支持 App scheme 才允许尝试打开，不能靠自行拼接一个登录 scheme 宣称授权成功。

Windows 不打包完整 Chromium，不把 Electron 或 Node 带入客户端。系统缺少 WebView2 时明确说明并提供官方安装入口及可用的扫码备用方式。插件选择以 Flutter 当前版本、各平台 Cookie API、会话隔离及打包实测为准，验证前不锁死具体插件。

不使用普通外部浏览器作为主路径：当前没有已验证的官方 OAuth 回调可把登录状态可靠交回本程序。不能假设打开浏览器后就可以读取浏览器 Cookie。

第一步必须真实验证：手机/Windows 网页登录后取得的凭据，能否从 NAS 出口识别同一账号并读取歌单与推荐。跨出口风控、验证码和接口变化属于可行性验证，不靠模拟测试下结论。网页链路未通过时仅对相应平台提供验证通过的扫码方式，并明确记录，不静默冒充网页登录可用。

## 4. 绑定交互和状态机

状态：未绑定、登录中、验证中、已绑定、已过期。网页加载失败、网络超时属于本次操作错误，不直接将已有绑定标为过期。

统一流程：

1. 已登录 Cyapi 用户发起绑定，后端创建短时绑定尝试，关联服务端认证用户和当前绑定版本。
2. 客户端用独立、临时官方网页会话完成登录；必要时跳转官方 App，恢复前台立即检查。
3. 通过原生 Cookie API 取得必要凭据，经 HTTPS 请求提交到当前 NAS 的本次绑定尝试；凭据不放 URL、剪贴板或日志。
4. NAS 查询网易云账号身份，取得可信 UID、昵称和头像。不能相信客户端提交的 UID、昵称或“成功”标记。
5. 验证成功后事务性替换绑定、更新绑定版本，返回公开账号信息；客户端关闭窗口，失效旧推荐缓存并刷新。
6. 登录窗口关闭、取消、超时或后端地址/Cyapi 会话改变，取消本次操作并清理临时网页登录数据。

更换账号时旧绑定保留，新绑定验证成功才替换。一个 Cyapi 用户同一时刻只保留一个有效绑定尝试，新尝试使旧尝试失效；多设备晚到结果不能覆盖新绑定或复活已解绑账号。后端重启后短时尝试失效，重新登录即可，已保存绑定继续保留。

二维码绑定：二维码由 NAS 创建，尝试与当前 Cyapi 用户关联；仅客户端前台弹窗轮询，后端限制查询频率并合并并发查询。确认后由 NAS 获取并验证凭据，不接受客户端任意指定要绑定的 Cyapi 用户。关闭弹窗停止轮询，过期由用户点击刷新。

网页会话只加载官方 HTTPS 登录及经验证必需的官方授权域名。App scheme、弹窗和导航均受控，业务 API 不允许提交任意 URL 让 NAS 代理。网页登录拿到 Cookie 后仍要按白名单和格式约束接收；敏感提交接口关闭请求体日志。

## 5. 凭据存储、部署和恢复

- 一名 Cyapi 用户绑定一个网易云账号；不对网易云 UID 加全局唯一限制，避免无意义地禁止用户在不同 Cyapi 账号使用自己的同一网易云账号。
- Cookie、CSRF 等凭据只保存在 NAS，加密后入库；对外只返回状态、UID、昵称、头像、绑定版本及更新时间。
- 使用标准库 AES-GCM，随机 nonce，密文包含格式/密钥版本，关联认证用户、平台与格式以防密文跨账号替换。
- 专用随机加密密钥首次使用时自动生成，通过受管路径和服务用户身份创建，限制文件权限；不复用登录 JWT 密钥，不要求用户手工填写。
- 密钥与绑定数据必须进入现有备份/恢复闭环，按恢复文件清单和校验机制处理；不能只备份数据库而漏掉密钥。
- 有加密绑定数据时缺失或损坏密钥，不得静默生成新密钥覆盖；doctor 给出脱敏诊断，说明恢复密钥或重新绑定的处理。
- 仅删除凭据不等于注销网易云官方账号；解绑删除本服务保存的有效凭据，并失效客户端/后端个人缓存。
- 客户端提交凭据要求 HTTPS，沿用现有公网访问地址，无新增固定 public URL 或代理配置。网页凭据提交入口在 HTTP 地址上不可用，提示使用 HTTPS；NAS 扫码路径的安全性单独控制，因为它不向客户端传递平台 Cookie。
- 检查安装、配置修改、升级、备份命令的受管 UID 与路径处理，避免再次由 root 创建业务文件造成权限问题。

数据库使用新迁移，兼顾 SQLite/PostgreSQL。绑定版本在解绑后仍应能单调递增，可用保留状态记录/版本字段实现，不能删除后重置版本导致旧请求重新匹配。

## 6. 后端接口和业务边界

新增网易云账号业务模块，继续采用 HTTP → service → persistence/provider 分层。复用现有 HTTP transport、超时、并发限制和数据库，不新增通用插件框架或微服务。

拟定接口，实施前在路由契约中定稿：

| 接口 | 作用 |
| --- | --- |
| `GET /accounts/bindings` | 当前绑定公开状态，网易云支持真实状态、酷狗明确不支持 |
| `POST /accounts/netease/bind-sessions` | 创建 web 或 qr 绑定尝试 |
| `GET /accounts/netease/bind-sessions/{id}` | 查询本用户尝试及扫码状态，必要时限频查询上游 |
| `POST /accounts/netease/bind-sessions/{id}/complete` | 提交网页登录凭据，由 NAS 验证身份并完成绑定 |
| `DELETE /accounts/netease/bind-sessions/{id}` | 取消尝试，阻止晚到结果提交 |
| `POST /accounts/netease/unbind` | 幂等解绑并失效绑定版本、未完成尝试与缓存 |
| `GET /netease/user/playlists` | 分页读取当前绑定账号歌单 |
| `GET /recommend/songs` | 每日推荐歌曲 |
| `GET /recommend/resource` | 每日推荐歌单 |
| `GET /personal_fm` | 按需获取 FM 一批歌曲 |

所有用户归属均从 Cyapi 认证主体取得，不接受请求中的 userId 作为授权依据。绑定尝试使用不可预测标识、有时限和数量上限；敏感提交限制请求体大小、Cookie 名称和值、重放和请求频率。旧占位路由只能有一个注册方，实现后移除对应静态注册，避免重复注册或继续返回假空数据。

网易云过期、未绑定、上游限流、超时、部分数据失败使用明确业务码。Cyapi 认证失效才返回 HTTP 401；网易云绑定失效使用例如 HTTP 409 + `NETEASE_LOGIN_EXPIRED`，未绑定使用 `NETEASE_NOT_BOUND`。客户端专门处理，不能触发全局 Cyapi 401 登出。

平台请求的个人凭据不可通过修改共享 Client.cookie 注入；使用显式不可变的请求身份，共用连接池和进程级并发预算。个人接口不能回退到服务器 NETEASE_COOKIE，公开接口维持既有行为。

## 7. 歌单与播放

“导入歌单 → 网易云账号”展示创建/收藏分类、分页、封面、歌曲数，多选操作提供：

- 复制为本地歌单：独立副本，自由增删，不回写网易云。
- 关注并同步：复用现有远程歌单快照、刷新、操作幂等和同步版本机制。

个人歌单详情读取必须支持当前绑定凭据；不能只让列表可见，而导入仍用匿名或全局 Cookie。沿用远程同步的身份/并发隔离设计，将绑定版本纳入任务身份。

完整获取一个歌单所需分页和歌曲详情后再提交该歌单结果。缺失、失败或取消不得把原歌单覆盖为不完整数据；展示明确错误，不把缺失歌曲默默算作成功。批量导入逐项展示进度和结果，失败项独立重试，同一次操作重试不重复创建；并发保持小且有上限。

来源标识至少包含平台、网易云 UID 和平台歌单 ID，不能用歌单名称去重。多设备晚到同步不能把旧账号内容写到新绑定账号的歌单操作中。

解绑后保留已导入副本和关注歌单快照；公开歌单可继续匿名同步，需要绑定权限的标记需重绑。更换平台账号后不自动把旧关注歌单换成新账号同名歌单。

推荐返回统一 Track/Playlist 模型、保留平台排序，复用现有播放器、队列、收藏和详情页面。本版不自动切换官方播放线路。FM 维护当前批次、去重与按需补充，避免循环播放固定缓存；跳过只影响本地队列，本版不承诺回传反馈改变平台推荐。

## 8. 首页与三套主题

首页增加“发现”和“为你推荐”分栏，首次仍进入现有发现内容，记住该后端/当前 Cyapi 用户的上次分栏。现有“猜你喜欢”保持其原有含义，不混称为网易云推荐。

- 未绑定：一张简洁的网易云绑定引导卡，可以直接进入登录。
- 已绑定：每日推荐歌曲入口、私人 FM、每日推荐歌单。
- 已过期：清除可交互的旧账号推荐，展示账号身份及重新绑定入口，不踢出 Cyapi。
- 暂时网络失败：同一绑定的已有内容可继续展示，附更新时间和重试。
- 单个模块失败：局部错误和重试，其它模块正常使用；无数据有独立空态，不把异常统一解释成“暂无推荐”。

优先复用 HomeForYouTab 和已有卡片，但重新整理其加载、身份及缓存；第一版只启用验证通过的三个模块，不并行开启六组旧请求。“专属/雷达/新歌”未核实前不展示，不把公开热门数据标为个性化。

Windows 登录采用主题一致的窗口外框，移动端用完整登录页；官方页面保持官方内容，不重做网易云密码/验证码表单。Material、Fluent、Cupertino 使用各自现有按钮、提示、弹窗和加载控件；长昵称、长域名、小窗口和系统缩放不溢出。

## 9. 缓存与资源

- 个人缓存身份包含后端、Cyapi 用户和绑定版本；每日歌曲还包含网易云所在时区的日期（按 Asia/Shanghai 处理），不使用 NAS 随意时区的午夜。
- 绑定、更换、解绑、Cyapi 退出和后端切换取消相关请求，并清理对应缓存；服务端提交及客户端赋值均校验身份版本。
- 推荐页按可见性加载，不在后台周期抓取；隐藏、离开或切后台停止扫码/页面轮询。
- 每日推荐缓存到次日边界，个人歌单使用短期缓存，手动刷新受限频；FM 按需补充而非跨会话长期缓存。
- 所有新增缓存有容量和条数上限，共用进程请求预算。不同账号不能复用个人响应；不新增每用户常驻 HTTP 客户端、后台线程或无限内存会话。
- 绑定验证期间及关键请求收到明确平台未登录结果才标记过期；超时、429、5xx 不误判凭据失效。

## 10. 实施阶段与交付门槛

### P0：真实可行性验证

验证 Windows WebView2 和手机 WebView 的 Cookie/临时会话/打包；NAS 出口完成账号识别、扫码、个人歌单、每日歌曲、推荐歌单、FM。检查 weapi 加密需求，参考 Q-music 在 Go 内实现必要协议。无真实账号时记录为未验证，不宣称完成。iOS 无真机条件单独标注。

输出：上游请求契约、客户端插件选择、平台支持矩阵、失败和风控观察、可复现的脱敏证据。失败能力不先做成可点击入口。

### P1：后端绑定与恢复闭环

实现新迁移、加密密钥生命周期、绑定尝试、凭据验证、版本更新、查询解绑和错误码；完善受管权限、doctor、备份恢复。验证 SQLite 与 PostgreSQL 契约和 NAS 升级保留已有账号歌单。

### P2：客户端登录与账号管理

Windows/移动端官方网页登录、备用扫码、三主题状态、Cookie 清理、取消与过期、更换账号；酷狗暂不支持。完成从手机绑定后 Windows 查询到同一绑定的跨设备验证。

### P3：个人歌单和推荐闭环

歌单分页、多选复制/关注、失败重试及去重；首页接入三个推荐模块；日推详情和 FM 接入播放队列。移除对应后端占位路由及误导文案。

### P4：集中验收与发布

实现时补齐有意义的回归测试，阶段内验证依赖，最后集中跑完整质量门禁和人工端到端，减少反复打包交给用户测试。Go 与客户端分别提交、构建，按现有发行机制发布；后端先部署，客户端后发布。当前文档不代表已授权自动发布或已完成真实账号验收。

## 11. 必须通过的验收清单

- Windows 官方窗口和 Android 官方网页完成真实登录；二维码备用路径可用，窗口取消后无继续查询或绑定。
- NAS 重启、客户端重开后绑定仍可用；手机绑定后桌面共享同一绑定。
- A/B 两个 Cyapi 用户、两个网易云账号并发，无 Cookie、推荐缓存、导入结果串号。
- 同时在两设备绑定、更换、解绑时，旧验证和同步结果不能覆盖或复活新状态。
- 过期只提示重绑网易云；Cyapi 401 才跳 Cyapi 登录页；超时/限流不误解绑。
- 创建/收藏歌单完整分页、超过单页歌曲数的完整导入、重复操作、失败重试及取消保留原数据。
- 日推排序、日期更新、FM 后续批次、去重、播放队列及离开页面后的生命周期。
- 日志、HTTP 错误、崩溃信息不含凭据；绑定 API 不返回 Cookie，不在 URL 中传递秘密。
- 备份在另一目录恢复后能解密绑定；缺密钥不会生成新密钥破坏既有绑定。
- SQLite/PostgreSQL、安装/升级权限、旧数据保留、Windows release 和 Android 签名安装验证。
- 三套主题、小屏/长文本/桌面缩放；iOS 登录、Cookie 和返回流程另行真机验收。

## 12. 交付后的使用流程

升级 NAS 后端和客户端 → 设置/第三方账号/网易云 → 官方网页登录（或扫码）→ 首页“为你推荐”与个人歌单导入可用。

不需要填写网易云 Cookie，不需要新增公网回调域名或 public URL，不增加 NAS 常驻服务。现有全局 Cookie 不被用户绑定覆盖。


## 13. 本次实施结果（2026-10-30）

后端已新增 `internal/neteaseaccount`、`internal/persistence/accountstore`、SQLite/PostgreSQL `0003_netease_accounts.sql`，直接通过现有 Go 网易云客户端实现 weapi。登录凭据仅存 AES-GCM 密文，AAD 包含 Cyapi 用户 ID，绑定版本用于阻止旧登录、推荐和导入结果覆盖新状态。没有增加 NAS 常驻服务或 Node 依赖。

客户端选用 `flutter_inappwebview ^6.1.5`。Windows 使用系统 WebView2 和独立临时用户目录；Android/iOS 使用系统 WebView，通过原生 Cookie API 获取必要凭据。官方页面导航受控，Windows 缺少 WebView2 会提示安装或扫码；手机支持官方 `orpheus://` App 跳转与回到前台检查。正式环境网页登录提交要求客户端使用 HTTPS 服务器地址；本机测试仅额外允许显式 localhost/127.0.0.1/IPv6 回环 HTTP 地址；TLS 在现有公网入口终止，后端不通过随意信任转发头来猜测 HTTPS，也不新增 public URL。

### 已实现接口

| 接口 | 行为 |
| --- | --- |
| `GET /accounts/bindings` | 查询服务端绑定状态及公开账号信息，酷狗返回 unsupported |
| `POST /accounts/netease/bind-sessions` | 创建 web / qr 短时尝试 |
| `GET /accounts/netease/bind-sessions/{id}` | 查询扫码进度，合并并发轮询，限频 |
| `POST /accounts/netease/bind-sessions/{id}/complete` | 验证网页登录凭据并提交绑定 |
| `DELETE /accounts/netease/bind-sessions/{id}` | 取消当前用户本次尝试 |
| `POST /accounts/netease/unbind` | 清除凭据、递增版本并失效尝试和缓存 |
| `GET /netease/user/playlists?limit=100&offset=0` | 当前绑定账号的分页歌单 |
| `GET /recommend/songs`、`GET /recommend/resource` | 日推歌曲和推荐歌单 |
| `GET /personal_fm` | 按需获取 FM，不长期缓存批次 |
| `POST /playlists/import` | 完整快照事务性创建本地歌单，支持 operationId 重试 |

这些接口均使用 Cyapi 登录保护。网易云未绑定、过期、版本变化使用业务 409；仅 Cyapi 认证失败使用 401。不会把上游 Cookie 放进客户端响应。

### 客户端和资源边界

- 设置仍为“第三方账号”；网易云支持绑定、更换、解绑和个人歌单，酷狗及其账号歌单导入明确暂不支持。
- 首页增加“发现 / 为你推荐”，每个后端和 Cyapi 用户独立记忆选择。推荐只启用日推歌曲、推荐歌单和私人 FM；各模块独立显示失败和重试。
- 个人歌单按页加载，可筛选创建/收藏、多选复制为本地或关注同步。返回会停止后续导入，当前事务可能已经完成；不会出现半张本地歌单。
- FM 使用独立 `neteaseFm` 队列来源，保留普通歌曲的播放恢复能力；根据队列尾部按需补充，换队列后停止，队列最多保留约 200 首，去重集合有上限。
- 客户端推荐不使用只有 Cyapi 身份的通用缓存；服务端缓存包含用户与绑定版本，最多 16 项，每项 512 KiB。日推按上海时区过日失效，其他缓存 3 分钟；解绑时清除该用户缓存。
- 每进程最多 256 个短时绑定尝试；查询个人内容每用户每分钟 60 次。退出、后端切换、隐藏推荐页和进入后台会失效或取消对应请求。
- 首次服务启动自动生成 `runtime_directory/netease.key`，不用手填。备份即使未传 `--include-config` 也保存已生成的凭据密钥；恢复必须与数据库配套。doctor 保持只读检查，不生成缺失数据库或新密钥。
